# Contributing

Start with the architecture index and the feature execution plan. The repository currently contains specifications and module boundaries; build/test commands will be documented when runnable projects are introduced.

Use focused changes, update affected architecture/spec status, and include relevant verification evidence. Never copy private Minicloud/TeamCore implementation, credentials, production settings, or customer data into this repository. Use synthetic examples and explicit configuration placeholders. Dependency and upstream harness licenses must be checked before redistribution.

The project license is pending selection. Do not assume an open-source license or advertise redistribution rights before it is added.
