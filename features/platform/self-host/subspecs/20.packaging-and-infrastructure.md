# Subspec: Self-Host Packaging and Infrastructure

Task: `T20`  
Status: Complete

## Scope & Deliverables

- **Containerization (`deploy/`)**:
  - `deploy/Dockerfile.api`: Multi-stage build compiling `MuniClaw.Api` (.NET 10 SDK -> ASP.NET Core runtime), exposes port 5000, installs curl for health checks, sets up `/var/lib/municlaw/data` and `/var/lib/municlaw/secrets` directories.
  - `deploy/Dockerfile.worker`: Multi-stage build for `MuniClaw.Worker`, provisions sandbox directory `/tmp/municlaw/tasks` (with `1777` permissions), installs `git`, `curl`, `bash`, `ca-certificates`, and `jq`.
  - `deploy/Dockerfile.dashboard`: Multi-stage build for `modules/ui/dashboard` (Node 22 / Vite build -> unprivileged Nginx on port 8080).
  - `deploy/nginx.conf`: Nginx configuration routing `/api` to `api:5000` with Server-Sent Events (SSE) streaming support (`proxy_buffering off`, `Cache-Control no-cache`, `X-Accel-Buffering no`), API health check passthrough, static asset caching, and SPA fallback via `try_files $uri $uri/ /index.html`.
- **Compose Orchestration (`deploy/docker-compose.self-host.yml`)**:
  - Multi-service deployment: `municlaw-api`, `municlaw-worker`, and `municlaw-dashboard`.
  - Service health checks for API service (`curl -f http://localhost:5000/health`) with dependency gates for worker and dashboard.
  - Persistent named volumes for data (`municlaw_data`), secrets (`municlaw_secrets`), and sandbox tasks (`municlaw_tasks`).
  - Configurable environment variables: `MUNICLAW_MASTER_KEY`, `MUNICLAW_API_URL`, `MUNICLAW_STORAGE_PATH`, `MUNICLAW_SECRET_PATH`, `MUNICLAW_PORT`, `MUNICLAW_API_PORT`.
  - Dedicated bridge network `municlaw-net` with service aliases (`api`, `worker`).
- **Host Automation (`scripts/self-host/`)**:
  - `scripts/self-host/bootstrap-host.sh`: Idempotent Linux host setup script for Ubuntu 22.04+, Debian 12+, RHEL 9+, Rocky/AlmaLinux. Detects system architecture (`x86_64` / `arm64`), checks and installs Docker engine, downloads and installs pinned OpenCode v1.18.32 binary to `/usr/local/bin/opencode`, creates the `municlaw` system user and group, provisions `/var/lib/municlaw` and `/tmp/municlaw/tasks`, creates `/etc/municlaw/worker.env` template, and hardens permissions (`0750` home, `0700` data/secrets, `1777` tasks sandbox).
  - `scripts/self-host/municlaw-worker.service`: Production systemd service unit running the dedicated worker supervisor under the unprivileged `municlaw` user with sandboxing protections (`ProtectSystem=full`, `ProtectHome=read-only`, `LimitNOFILE=65536`).
- **Operations & Architecture Guide (`docs/architecture/self-host-guide.md`)**:
  - Production-ready operational guide covering standalone architecture, hardware/OS prerequisites, master key generation (AES-256-GCM), single-node Docker Compose quickstart, dedicated Worker VPS deployment, backup/restore procedures with atomic guarantees, SSL reverse proxy configurations (Caddy, Nginx), and troubleshooting.
