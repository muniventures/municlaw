# Subspec: Notification Channels Console UI

Task: `T20`
Status: Complete

## Scope

- API client methods for notification channel management and test notification pings.
- Notifications management view in `modules/ui/dashboard/app/modules/Settings/components/NotificationChannels.tsx`.
- Add/Edit Channel modal with Slack / Discord / Generic Webhook presets, secret key display for Generic webhooks, and event subscription checkboxes.
- Immediate "Send Test Ping" validation with visual feedback.

## Implementation Summary

1. **TypeScript Definitions (`modules/ui/dashboard/app/api/types.ts`)**:
   - Added `NotificationChannelType`: `'Slack' | 'Discord' | 'GenericWebhook'`.
   - Added `NotificationEventType`: `'ApprovalRequested' | 'TaskCompleted' | 'TaskFailed' | 'DeliveryPublished'`.
   - Added `NotificationChannel` interface with id, organizationId, channelType, name, maskedWebhookUrl, subscribedEvents, isEnabled, createdAt, optional lastDispatchedAt and lastDispatchStatus, and optional hasSigningSecret.
   - Added `CreateNotificationChannelRequest` and `UpdateNotificationChannelRequest`.

2. **API Client (`modules/ui/dashboard/app/api/notifications.ts`)**:
   - `listChannels(orgId)`: GET `/api/v1/organizations/{orgId}/notifications/channels`.
   - `createChannel(orgId, req)`: POST `/api/v1/organizations/{orgId}/notifications/channels`.
   - `updateChannel(orgId, channelId, req)`: PUT `/api/v1/organizations/{orgId}/notifications/channels/{channelId}`.
   - `deleteChannel(orgId, channelId)`: DELETE `/api/v1/organizations/{orgId}/notifications/channels/{channelId}`.
   - `sendTestPing(orgId, channelId)`: POST `/api/v1/organizations/{orgId}/notifications/channels/{channelId}/test` (with `/ping` fallback).

3. **Console UI Component (`modules/ui/dashboard/app/modules/Settings/components/NotificationChannels.tsx`)**:
   - Channel list view with Type badges (Slack with # hash icon, Discord with bell icon, Generic Webhook with webhook icon).
   - Display channel name, masked URL (monospace, write-only/redacted), subscribed event badges, enabled/disabled status.
   - Accessible toggle switch for instantaneous enable/disable with optimistic UI update and error rollback.
   - Immediate "Test Ping" button with spinner during dispatch and toast/inline status feedback.
   - Edit button opening dialog with pre-populated channel values and write-only masked webhook placeholder.
   - Delete button with confirmation guard.
   - "Add Channel" and "Edit Channel" modal dialog:
     - Name input (required).
     - Channel type selector (`Slack`, `Discord`, `GenericWebhook`).
     - Webhook URL input with URL protocol validation and write-only preservation on edit.
     - Subscribed event checkboxes (`ApprovalRequested`, `TaskCompleted`, `TaskFailed`, `DeliveryPublished`) with "Select all" / "Deselect all" shortcuts.
     - Generic Webhook: signing secret input and random high-entropy generator with HMAC-SHA256 signature documentation.

4. **Settings Module Navigation Tabs (`modules/ui/dashboard/app/modules/Settings/SettingsModule.tsx`)**:
   - Added `Tabs` with "Policies", "General", and "Notifications" navigation tabs.
   - Render `NotificationChannels` component when the Notifications tab is active.

   - Component validation tests in `modules/ui/dashboard/app/modules/Settings/components/NotificationChannels.test.ts` (7 tests).
