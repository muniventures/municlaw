# Feature: Outbound Messaging Adapters and Webhooks

Scope: Outbound notification dispatch for task lifecycle events to Slack, Discord, and Generic HTTP Webhooks with HMAC-SHA256 signing, event filtering, and console management.

## Agent instructions

- Use stable task IDs (`T10`, `T20`, `T90`).
- Keep live task status in `0.execution-plan.md`.
- After finishing tasks, update subspecs, `0.execution-plan.md`, `features/FEATURE_BACKLOG.md`, and `features/FEATURES_REGISTRY.md`.
- Dispatched webhooks must never expose raw model API keys, secret credentials, or administrative tokens.
- Generic webhooks must include an HMAC-SHA256 signature in the `X-MuniClaw-Signature` header so receivers can authenticate payloads.

## Goal

Notify developers and team leads in their existing chat workflows (Slack, Discord) or via HTTP webhooks when a MuniClaw coding task finishes, requires human approval to proceed, encounters an unrecoverable failure, or successfully opens a draft pull request.

## Current patterns learned

- `TaskLifecycleService`, `ApprovalService`, and `DeliveryService` orchestrate lifecycle events.
- Domain models in `modules/core/Models/DomainModels.cs` are persisted via `IMuniClawStore` and `MuniClawFileStore`.
- React console Settings module currently manages organization policy settings.

## Scope and non-goals

### In scope

- Notification channel types:
  - `Slack`: Formatted Slack Block Kit messages with direct "View in Console" action button.
  - `Discord`: Formatted Discord Embeds with color-coded severity borders (orange for approval, green for complete, red for failed).
  - `GenericWebhook`: Raw JSON event payload with HMAC-SHA256 signature (`X-MuniClaw-Signature`) and timestamp headers (`X-MuniClaw-Timestamp`).
- Subscribable event types:
  - `ApprovalRequested`: Task paused and waiting for human approval.
  - `TaskCompleted`: Task coding finished with diff and check results ready for review.
  - `TaskFailed`: Task aborted or failed with error summary.
  - `DeliveryPublished`: Draft PR/MR successfully created or updated on GitHub/GitLab.
- Webhook management in Console Settings:
  - Create, test, update, and delete notification channels.
  - Subscribed event toggle switches.
  - Live "Send Test Ping" validation.

### Out of scope

- Inbound chat bots (e.g. executing coding tasks directly from Slack slash commands / interactive chat replies) - reserved for future agent bot roadmap.
- SMS / pager duty telephone dialing.

## Requirements

### Runtime and dispatch requirements

- Dispatches are non-blocking and fire asynchronously without impeding the core task lifecycle or worker execution loops.
- Secret webhook URLs are write-only upon creation and masked in all API responses.
- Generic webhooks compute `HMAC-SHA256(secret, timestamp + "." + body)`.

### Verification

- Automated tests verifying payload formatting for Slack, Discord, and Generic Webhook.
- Automated tests verifying HMAC signature computation and validation.
- Automated tests verifying event filtering (unsubscribed events do not trigger delivery).
- Automated tests verifying that task state transitions trigger appropriate notification dispatches.
