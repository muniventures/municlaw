## Phase plan

1. **T10 (Core & Worker)**:
   - Add `HarnessType` enum/string (`OpenCode`, `ClaudeCode`) to `DomainModels.cs` and `TaskContracts.cs` (defaulting to `OpenCode`).
   - Define `IHarnessSupervisor` and `IHarnessRegistry` in `modules/worker/Harness/`.
   - Update `OpenCodeSupervisor` to implement `IHarnessSupervisor`.
   - Implement `ClaudeCodeHarnessAdapter` implementing `IHarnessAdapter` with `ClaudeCodeEventMapper`.
   - Implement `ClaudeCodeSupervisor` implementing `IHarnessSupervisor`.
   - Implement `HarnessRegistry` registering both `OpenCode` and `ClaudeCode` supervisors.
   - Update `WorkerSupervisor` to resolve harness dynamically via `IHarnessRegistry` using `claim.HarnessType` / `claim.HarnessVersion`.
2. **T20 (Console UI)**:
   - Add `harnessType` field to `CreateTaskRequest` and `TaskRun` in `types.ts`.
   - Update `TaskCreateModal.tsx` with Harness selector ("OpenCode v1.18.32" / "Claude Code").
   - Update `TaskDetailModule.tsx` and `TaskList.tsx` with harness badge indicator.
3. **T90 (Qualification)**:
   - Tests in `MuniClaw.Worker.Tests`:
     - `ClaudeCodeHarnessAdapter` session creation, prompt dispatch, event streaming, diff extraction.
     - `ClaudeCodeEventMapper` canonical event mapping.
     - Sub-100ms abort for Claude Code.
     - `HarnessRegistry` dynamic resolution and fallback.
   - Tests in `MuniClaw.Tests`:
     - Task creation with explicit `HarnessType = ClaudeCode`.
     - Worker claim and harness type routing.
