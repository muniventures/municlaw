# Subspec: Pluggable Harness Contracts and Worker Adapters

Task: `T10`
Status: Complete

## Scope

- Domain models and contracts:
  - Added `HarnessType` enum (`OpenCode = 0`, `ClaudeCode = 1`) to `DomainModels.cs`.
  - Added `HarnessType` to `CreateTaskRequest` in `TaskContracts.cs`, `TaskRun` in `DomainModels.cs`, and `WorkerClaimResponse` in `WorkerContracts.cs`.
  - Propagated `HarnessType` in `TaskLifecycleService.CreateTaskAsync` and `CreateFollowUpRunAsync`.
  - Populated `HarnessType = nextRun.HarnessType` in `WorkerDispatchService.ClaimWorkAsync`.
- Pluggable worker harness interfaces:
  - Defined `IHarnessSupervisor` interface (`string HarnessType`, `string PinnedVersion`, `bool IsRunning`, `IHarnessAdapter Adapter`, `Task StartAsync(CancellationToken ct)`, `Task StopAsync(CancellationToken ct)`).
  - Defined `IHarnessRegistry` interface (`void Register(IHarnessSupervisor supervisor)`, `IHarnessSupervisor GetSupervisor(string harnessType)`, `IReadOnlyList<IHarnessSupervisor> GetAllSupervisors()`).
  - Implemented `HarnessRegistry` storing supervisors and defaulting to `OpenCode` supervisor when unknown or empty.
  - Updated `IOpenCodeSupervisor` to inherit `IHarnessSupervisor` and `OpenCodeSupervisor` to implement `HarnessType => "OpenCode"`.
- Claude Code harness adapter:
  - Created `ClaudeCodeEventMapper` in `ClaudeCodeContracts.cs` mapping Claude Code stream events to canonical `TaskEventType` (`text_delta`/`assistant_response` -> `TextDelta`, `thought_delta`/`reasoning` -> `ReasoningDelta`, `tool_call`/`tool_use` -> `ToolCalled`, `tool_result` -> `ToolSuccess`, `tool_error` -> `ToolFailed`, `diff` -> `DiffUpdated`, `ask_user` -> `ApprovalRequested`, `error` -> `Error`).
  - Created `ClaudeCodeHarnessAdapter` implementing `IHarnessAdapter`:
    - `CreateSessionAsync`: creates sandbox-bound sessions.
    - `SendPromptAsync`: dispatches prompt via headless CLI execution or in-memory mock when binary not present.
    - `GetDiffAsync`: parses git diff via `git diff --numstat` in the session working directory.
    - `AbortAsync`: terminates processes within sub-100ms bound (<1ms measured).
    - `SubscribeEventsAsync`: streams raw events mapped via `ClaudeCodeEventMapper`.
  - Created `ClaudeCodeSupervisor` implementing `IHarnessSupervisor` (`HarnessType => "ClaudeCode"`, `PinnedVersion => "1.0.0"`).
- Worker supervisor update:
  - Updated `WorkerSupervisor` to support `IHarnessRegistry` with backward-compatible constructor for `IOpenCodeSupervisor`.
  - In `ExecuteClaimedRunAsync`, dynamically resolves harness supervisor using `claim.HarnessType.ToString()`.
  - Normalizes events from either OpenCode or Claude Code runtimes into canonical task events.
