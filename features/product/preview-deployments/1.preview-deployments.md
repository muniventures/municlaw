# Preview Deployments Integration

Status: In progress
Owner: MuniClaw Team

## Goal

Enable automated and on-demand ephemeral preview deployments for MuniClaw coding tasks on Minicloud infrastructure or compatible branch deployment environments, allowing reviewers to visually interact with and verify running applications directly from the task branch before merging.

## Context & Architecture

MuniClaw isolates coding sessions on dedicated task branches (`municlaw/task-{taskId}`). Once a task run finishes and review commits are prepared or published, reviewers need an interactive verification environment running the actual web service or application.

Minicloud provides a branch deployment contract (`minicloud deploy branch`) that creates isolated child applications with normalized DNS subdomains: `<service>-<normalized-branch>.app.muni.dev`.

### Security Invariants

1. **Production Secret Isolation**: Coding environments, worker sandboxes, and preview deployments must NEVER copy or access production secrets. Previews receive only explicit preview-scoped configuration or mock secrets.
2. **Reviewer / Organization Authorization**: Only users authorized for the organization and repository may trigger or destroy preview deployments.
3. **Branch Normalization**: Branch names must be normalized to lowercase, DNS-safe alphanumeric labels with hyphen separators, preventing header or DNS injection attacks.
4. **Lifecycle & Teardown**: Preview environments are ephemeral and can be explicitly destroyed by reviewers or automatically expire.

## Core Capabilities

1. **Preview Lifecycle Management**:
   - `PreviewDeploymentStatus`: `None`, `Deploying`, `Active`, `Failed`, `TornDown`.
   - `PreviewDeployment` entity tracked in store and linked to task and commit SHA.
   - Idempotent deploy triggers: requesting preview when already active returns the existing deployment.
2. **Provider Integration**:
   - `IPreviewDeploymentClient` interface supporting:
     - `TriggerPreviewAsync`: deploys branch and returns preview URL.
     - `GetPreviewStatusAsync`: polls status and health.
     - `TearDownPreviewAsync`: destroys preview environment.
   - Built-in Minicloud adapter and in-memory test provider.
3. **Outbound Notification Integration**:
   - Dispatches notifications to configured Slack, Discord, and Webhook channels when a preview is deployed or updated.
4. **Web Console UI**:
   - In `TaskDetailModule.tsx`:
     - Preview section with "Deploy Preview" button, deployment progress spinner, active status pill, live URL link, and "Tear Down" button.
     - Direct access from the task detail header and delivery tab.
