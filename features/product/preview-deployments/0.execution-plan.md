## Phase plan

1. **T10 (Core & API)**:
   - Add `PreviewDeployment` domain model and `PreviewDeploymentStatus` enum in `modules/core/Models/DomainModels.cs`.
   - Add `PreviewDeployments` dictionary to `IMuniClawStore`, `InMemoryMuniClawStore`, and `MuniClawFileStore`.
   - Define `IPreviewDeploymentClient` and implement `MinicloudPreviewDeploymentClient` with branch normalization (`NormalizeBranchName`) and URL template (`https://{service}-{normalizedBranch}.app.muni.dev`).
   - Implement `PreviewDeploymentService` handling `TriggerPreviewDeploymentAsync`, `GetPreviewDeploymentAsync`, and `TearDownPreviewDeploymentAsync`.
   - Add `PreviewController` (`POST /api/v1/tasks/{taskId}/preview`, `GET /api/v1/tasks/{taskId}/preview`, `DELETE /api/v1/tasks/{taskId}/preview`).
2. **T20 (Console UI)**:
   - Add TypeScript types and API client functions in `app/api/preview.ts` and `app/api/types.ts`.
   - Update `TaskDetailModule.tsx` with Preview Deployment card/header actions:
     - Deploy button when no active preview.
     - Deploying spinner state.
     - Active state showing external link icon, preview URL, and "Tear Down" button.
     - Error state showing failure reason and retry button.
3. **T90 (Qualification)**:
   - Automated tests in `modules/tests/MuniClaw.Tests/Program.cs` verifying:
     - Preview deployment trigger and URL generation.
     - Branch normalization safety (lowercase, DNS-safe, no special characters).
     - Secret isolation (previews do not inherit production credentials).
     - Idempotent triggers.
     - Explicit teardown and cleanup.
