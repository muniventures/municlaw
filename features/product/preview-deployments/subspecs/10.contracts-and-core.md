# Subspec: Preview Deployments Backend Contracts and Core Services

Task: `T10`
Status: Complete

## Scope

- Define `PreviewDeploymentStatus` (`None`, `Deploying`, `Active`, `Failed`, `TornDown`) and `PreviewDeployment` entity.
- Store persistence in `IMuniClawStore`, `InMemoryMuniClawStore`, and `MuniClawFileStore`.
- `IPreviewDeploymentClient` contract and `MinicloudPreviewDeploymentClient` implementation with DNS branch normalization.
- `IPreviewDeploymentService` handling deployment orchestration, task status checks, idempotency, and teardown.
- `PreviewController` exposing REST endpoints for triggering, querying, and tearing down previews.

## Implementation Details

1. **Domain Models (`modules/core/Models/PreviewModels.cs`)**:
   - `PreviewDeploymentStatus`: `None`, `Deploying`, `Active`, `Failed`, `TornDown`.
   - `PreviewDeployment`: Contains `Id`, `TaskId`, `RunId`, `OrganizationId`, `BranchName`, `NormalizedBranch`, `CommitSha`, `PreviewUrl`, `Status`, `CreatedAt`, `DeployedAt`, `TornDownAt`, and `ErrorMessage`.

2. **Contracts & DTOs (`modules/core/Contracts/Preview/PreviewContracts.cs`)**:
   - `TriggerPreviewRequest`: Request model accepting optional `CustomSubdomain`.
   - `PreviewDeploymentDto`: Contract projection with static `FromModel` conversion helper.

3. **Store Persistence (`modules/core/Data/MuniClawStore.cs` & `modules/core/Data/MuniClawFileStore.cs`)**:
   - Added `ConcurrentDictionary<Guid, PreviewDeployment> PreviewDeployments { get; }` to `IMuniClawStore`, `InMemoryMuniClawStore`, and `MuniClawFileStore`.
   - Incorporated `PreviewDeployments` in snapshot serialization (`SnapshotData`), atomic file persistence (`snapshot.json`), and reset routines.

4. **Integration Client (`modules/core/Integrations/PreviewDeploymentClient.cs`)**:
   - `IPreviewDeploymentClient`: `TriggerDeploymentAsync`, `CheckStatusAsync`, `TearDownDeploymentAsync`.
   - `MinicloudPreviewDeploymentClient`:
     - `NormalizeBranchName`: Converts to lowercase, converts non-alphanumeric characters to hyphens, collapses consecutive hyphens, trims leading/trailing hyphens, and for branch names exceeding 32 characters trims prefix and appends stable 8-character SHA256 hex suffix.
     - Constructs preview URL adhering to Minicloud branch deployment format: `https://{serviceLabel}-{normalizedBranch}.app.muni.dev`.
     - Enforces security invariant: preview deployments NEVER receive production secrets (isolated preview environment).
     - In-memory mock tracking of active and torn down deployments.

5. **Preview Deployment Service (`modules/core/Services/PreviewDeploymentService.cs`)**:
   - Implements `IPreviewDeploymentService` (`TriggerPreviewAsync`, `GetPreviewAsync`, `TearDownPreviewAsync`).
   - Verifies organization access via `IOrganizationAuthorizationService` and task existence.
   - Enforces idempotency: returning existing deployment if status is `Active` or `Deploying`.
   - Resolves latest run, delivery review commit SHA, and project service label.
   - Dispatches notification to `INotificationService` on activation with event type `DeliveryPublished`.

6. **API Controller (`modules/api/Controllers/PreviewController.cs`)**:
   - Exposes `POST /api/v1/tasks/{taskId}/preview`: triggers preview deployment.
   - Exposes `GET /api/v1/tasks/{taskId}/preview`: queries current preview deployment.
   - Exposes `DELETE /api/v1/tasks/{taskId}/preview`: tears down preview deployment.
   - Also supports organization-prefixed route `/api/v1/organizations/{organizationId}/tasks/{taskId}/preview`.
   - Resolves actor user ID from query, header (`X-User-Id`), or task creator/org member.

7. **Service Registration (`modules/api/Program.cs`)**:
   - Registered `IPreviewDeploymentClient` (`MinicloudPreviewDeploymentClient`), `IPreviewDeploymentService` (`PreviewDeploymentService`), and `INotificationService` (`NotificationService`).
