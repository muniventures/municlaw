# Subspec: Preview Deployments Console UI

Task: `T20`
Status: Complete

## Scope

- API client methods in `app/api/preview.ts` calling `/api/v1/tasks/{taskId}/preview`.
- `PreviewDeploymentCard.tsx` component embedded in `TaskDetailModule.tsx`.
- Displays current deployment status (Deploying, Active, Failed, TornDown).
- Action buttons: "Deploy Preview", "Open Preview App", "Tear Down Preview".
- Type safety and unit test coverage.

## Summary of Implementation

1. **TypeScript Types (`app/api/types.ts`)**:
   - Added `PreviewDeploymentStatus` union type (`'None' | 'Deploying' | 'Active' | 'Failed' | 'TornDown'`).
   - Added `PreviewDeployment` entity interface including `id`, `taskId`, `runId`, `branchName`, `normalizedBranch`, `commitSha`, `previewUrl`, `status`, `createdAt`, `deployedAt`, and `errorMessage`.

2. **API Client (`app/api/preview.ts`)**:
   - `getPreview(taskId: string): Promise<PreviewDeployment | null>`: fetches preview deployment status from `/api/v1/tasks/{taskId}/preview`, handling 404 cleanly by returning `null`.
   - `triggerPreview(taskId: string): Promise<PreviewDeployment>`: triggers on-demand preview deployment via `POST /api/v1/tasks/{taskId}/preview`.
   - `tearDownPreview(taskId: string): Promise<PreviewDeployment>`: dismantles preview deployment via `DELETE /api/v1/tasks/{taskId}/preview`.

3. **Preview Deployment Card Component (`app/modules/Tasks/components/PreviewDeploymentCard.tsx`)**:
   - Clean, modern card component adhering to the console theme using Lucide icons (`Globe`, `ExternalLink`, `Loader2`, `Trash2`, `Rocket`, `AlertTriangle`).
   - **No preview / TornDown state**: Displays "Preview Deployment" header, branch indicator, and a "Deploy Preview" button with rocket icon.
   - **Deploying state**: Displays pulsing spinner with `"Provisioning preview environment on Minicloud branch infrastructure..."`, along with background polling every 3 seconds until a terminal state is reached.
   - **Active state**: Displays green active badge `"Live Preview"`, clickable URL opening in a new tab with `ExternalLink` icon, branch indicator, and a "Tear Down" button with explicit confirmation dialog.
   - **Failed state**: Displays red failure badge `"Failed"`, the failure error message with warning icon, and a "Retry Deploy" button.
   - Built-in action error alerting and dismissibility.

4. **Task Detail Module Integration (`app/modules/Tasks/TaskDetailModule.tsx`)**:
   - Embedded `<PreviewDeploymentCard taskId={task.id} branchName={task.taskBranch} />` in the Task Detail view above the execution tabs for immediate visibility.

5. **Test Coverage & Verification**:
   - `app/api/preview.test.ts`: Vitest suite covering successful queries, 404 handling, error bubbling, deploy triggers, and teardown API invocations.
   - `app/modules/Tasks/components/PreviewDeploymentCard.test.tsx`: Vitest suite verifying component rendering across all lifecycle states (`No preview`, `TornDown`, `Deploying`, `Active`, `Failed`).
   - Verified clean TypeScript compilation (`npm run typecheck`), all tests passing (`npm test`), and production build succeeding (`npm run build`).
