# Subspec: Organization Credentials Backend Contracts and Core Logic

Task: `T10`
Status: Complete

## Scope

- Domain models: `OrganizationCredentialPolicy`, extended `ProviderCredentialReference`.
- Core services:
  - `ProviderCredentialService`: `RegisterOrganizationCredentialAsync`, `UpdatePolicyAsync`, `GetOrganizationCredentialsAsync`, `GetAccessibleCredentialsAsync`, `RecordSpendAsync`, `RevokeCredentialAsync`.
  - `TaskLifecycleService`: Model allowance checking, admin role enforcement, and spend cap enforcement upon `CreateTaskAsync` and `CreateFollowUpRunAsync`.
- Store updates: Thread-safe storage, policy updates, and spend accumulation for organization credentials in `IMuniClawStore` / `InMemoryMuniClawStore`.
- API endpoints:
  - `POST /api/v1/credentials/organization`
  - `GET /api/v1/credentials/organization`
  - `PUT /api/v1/credentials/organization/{credentialId}/policy`
  - `GET /api/v1/credentials/accessible`
  - `DELETE /api/v1/credentials/organization/{credentialId}`

## Implementation Summary

1. **Domain Models (`modules/core/Models/DomainModels.cs`)**:
   - Added `OrganizationCredentialPolicy` class:
     - `List<string> AllowedModels` (defaults to `["*"]`).
     - `decimal? MonthlySpendLimitUsd` (`null` = unlimited).
     - `decimal CurrentSpendUsd` (default `0m`).
     - `bool AdminOnly` (default `false`).
   - Extended `ProviderCredentialReference`:
     - Added `Policy` property (`OrganizationCredentialPolicy?`).
     - Maintained existing `CredentialScope Scope`.

2. **Integration Contracts (`modules/core/Contracts/Integrations/IntegrationContracts.cs`)**:
   - Added `RegisterOrganizationCredentialRequest(string OrganizationId, string Provider, string Label, string ApiKey, OrganizationCredentialPolicy? Policy = null)` with optional `UserId` init property.
   - Added `UpdateCredentialPolicyRequest(OrganizationCredentialPolicy Policy)`.

3. **Store Layer (`modules/core/Data/MuniClawStore.cs`)**:
   - Added thread-safe methods to `IMuniClawStore` and `InMemoryMuniClawStore`:
     - `StoreOrganizationCredential(ProviderCredentialReference credential)`
     - `GetOrganizationCredentials(Guid organizationId)` and string overload
     - `UpdateCredentialPolicy(Guid credentialId, OrganizationCredentialPolicy policy)`
     - `IncrementCredentialSpend(Guid organizationId, Guid credentialId, decimal amountUsd)` and string overload

4. **Credential Service (`modules/core/Services/ProviderCredentialService.cs`)**:
   - Implemented `RegisterOrganizationCredentialAsync`: Enforces `OrganizationRole.Admin` authorization via `OrganizationAuthorizationService`, securely scopes OpenBao secret path (`municlaw/{orgId}/org-credentials/{credId}`), and registers reference.
   - Implemented `UpdatePolicyAsync`: Verifies Admin role and updates policy while preserving accumulated spend.
   - Implemented `GetOrganizationCredentialsAsync`: Retrieves organization-scoped credentials for an organization.
   - Implemented `GetAccessibleCredentialsAsync`: Returns personal keys for `actorUserId` plus permitted organization keys (filtered by `AdminOnly` when caller is a non-admin member).
   - Implemented `RecordSpendAsync`: Accumulates spend thread-safely against the organization credential policy.
   - Updated `RevokeCredentialAsync`: Ensures only organization administrators can revoke organization-scoped credentials, cascading run cancellations.

5. **Task Lifecycle Validation (`modules/core/Services/TaskLifecycleService.cs`)**:
   - In `CreateTaskAsync` (and `CreateFollowUpRunAsync`): When resolving credentials with `Scope == CredentialScope.Organization`:
     - Verifies actor permission (`AdminOnly` check requiring Admin role).
     - Verifies requested model matches `AllowedModels` (supports exact match, `*` wildcard, and wildcard prefixes like `claude-*`).
     - Verifies monthly spend limit is not exceeded (`CurrentSpendUsd < MonthlySpendLimitUsd`).
     - Throws `InvalidOperationException` with clear informative error message on any violation.

6. **API Endpoints (`modules/api/Controllers/CredentialsController.cs`)**:
   - `POST /api/v1/credentials/organization` & `POST organization`: Registers org credential with policy.
   - `GET /api/v1/credentials/organization` & `GET organization`: Queries organization credentials.
   - `PUT /api/v1/credentials/organization/{credentialId}/policy` & `PUT organization/{credentialId}/policy`: Updates credential policy.
   - `GET /api/v1/credentials/accessible` & `GET accessible`: Returns accessible credentials for user/org.
   - `DELETE /api/v1/credentials/organization/{credentialId}` & `DELETE organization/{credentialId}`: Revokes org credential.
   - Redacts secret reference paths and raw secrets in all responses.

7. **Verification**:
   - `dotnet build MuniClaw.slnx` succeeds with 0 warnings and 0 errors.
   - All existing tests in `MuniClaw.Tests` continue to pass.
   - Comprehensive verification tests in scratch runner validated all positive and negative policy paths (admin verification, model matching, spend overflow, member accessibility).
