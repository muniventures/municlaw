## Verified Test Cases

| Test Case | Description | Result |

| `Admin authorization check` | Non-admin members attempting to register or update organization-scoped credentials receive 403 `UnauthorizedAccessException`. Admins succeed. | **PASS** |

| `Revocation cascade` | Revoking an organization credential cascades to terminate all actively running tasks using that credential with status `Failed` and reason `"Provider credential was revoked."`. | **PASS** |
