# Subspec: Organization Credentials Console UI

Task: `T20`
Status: Complete

## Scope

- UI endpoints and client functions for organization credential management.
- Connections view with tabbed interface: "Personal API Keys" and "Organization API Keys".
- Organization API Keys manager:
  - List of registered shared credentials with provider badge, model policy pill, and spend bar.
  - Add Organization Key dialog with model selection, monthly budget input, and Admin-only toggle.
  - Policy editor modal to update budget or allowed models.
  - Revocation confirmation dialog.
- Task Creation modal enhancement:
  - Model Provider Credential dropdown: allows picking personal keys or accessible organization keys.
  - Client-side validation indicating if a selected model is blocked by the chosen credential policy.

## Summary of Changes

1. **Domain Types (`types.ts`)**:
   - Added `OrganizationCredentialPolicy` interface supporting `allowedModels`, optional `monthlySpendLimitUsd`, `currentSpendUsd`, and `adminOnly`.
   - Updated `ProviderCredentialReference` with optional `policy: OrganizationCredentialPolicy`.
   - Added `RegisterOrganizationCredentialRequest` and `UpdateCredentialPolicyRequest` interfaces.
2. **API Methods (`connections.ts`)**:
   - Implemented `getOrganizationCredentials(orgId)` with endpoint fallback logic.
   - Implemented `registerOrganizationCredential(orgId, payload)` for encrypted write-only shared key registration.
   - Implemented `updateCredentialPolicy(orgId, credentialId, policy)` for updating model allowlists and budget caps.
   - Implemented `getAccessibleCredentials(orgId)` for loading deduplicated personal and organization credentials.
   - Implemented `revokeOrganizationCredential(orgId, credentialId)` with fallback.
3. **Connections UI (`ConnectionsModule.tsx` & `OrganizationCredentialManager.tsx`)**:
   - Created tabbed interface dividing Personal API Keys and Organization API Keys.
   - Built `OrganizationCredentialManager` displaying shared credentials, provider badges, model policy pills, live spend tracker progress bar ($Current / $Limit), and Admin-Only badges.
   - Added write-only "Add Organization Key" dialog with provider selection, presets/custom model allowlist input, monthly budget cap, and admin-only toggle.
   - Added "Edit Policy" dialog to adjust allowed models, monthly spend budget, and admin restrictions.
   - Implemented Revocation confirmation dialog with task abort warnings.
4. **Task Launch Integration (`TaskCreateModal.tsx`)**:
   - Integrated `getAccessibleCredentials` to fetch both personal and organization shared credentials.
   - Added explicit badge prefixes: `[Personal]` vs `[Org Shared]` (with Admin-Only tags).
   - Added client-side policy validation warning and dispatch prevention when a selected model is disallowed by an organization key's policy or when budget caps are exceeded.
5. **Testing and Verification**:
   - Added unit test suite in `connections.test.ts` and `TaskCreateModal.test.ts`.
   - Verified clean compilation with `npm run typecheck`, 100% test passage with `npm test` (14/14 tests passing), and production build with `npm run build`.
