# T20: VPS worker and isolation

Status: Complete.
Depends on: T00.
Can run in parallel with: T10.

## Work

- Bootstrap the trusted supervisor on a dedicated organization VPS with one-time registration and revocable outbound credentials.
- Create per-task worktree, branch, unprivileged sandbox, home, and pinned OpenCode process. Enforce measured CPU/memory/process/storage/time/network limits.
- Keep supervisor credentials and host/container-management sockets inaccessible from harness and repository commands.
- Implement outbound HTTP long-poll claims, leased/fenced ownership, heartbeat command cursors, trusted Git/model helpers, versioned setup approval, normalized event forwarding, bounded local buffering, and idempotent acknowledged uploads.
- Persist session mappings and execution ownership; implement abort, lease-loss termination, startup reconciliation, and safe resumption.
- Implement seven-day retention from the latest terminal run, disk-pressure admission rejection, deletion, published-branch reconstruction into a new session, and observable provisioning/runtime failures. Do not imply recovery of unpublished deleted work.

## Acceptance

- Two organization VPSes cannot register as or fetch work for each other. Task sandboxes cannot access another task's files or host credentials.
- Restart, API outage, duplicate dispatch, expired lease, and cancellation preserve an accurate task state and prevent overlapping execution.
- Long-running child processes stop within T00's bound; incomplete work remains inspectable.
- Metadata/private management networking and host Docker access are denied. Resource exhaustion is contained and surfaced.
- Lost VPS storage is reported explicitly; cleanup never silently erases active work.

## Implementation & Test Evidence (2026-09-28)

1. **Worker Background Service & Claim Loop**:
   - `modules/worker/Supervisor/WorkerSupervisor.cs`: Polling service querying `POST /api/v1/worker/claim` with `WorkerId`, `OrganizationId`, and `SupportedHarnessVersion`. Enforces single active executing task per supervisor.
2. **Leased Heartbeat Protocol, Command Cursor & Immediate Lease-Loss Termination**:
   - Initial handshake and periodic background heartbeat against `POST /api/v1/worker/heartbeat`.
   - Renews lease token and preserves fencing token monotonic ordering.
   - Command cursor dispatch: polls and delivers pending `WorkerCommand` items (`Abort`, `Cancel`, `Resume`, `Reconcile`), advancing `LastAcknowledgedCommandCursor`.
   - Immediate lease-loss termination: if server returns `IsLeaseValid == false` or HTTP 410 Gone, supervisor terminates execution immediately, halting child processes and avoiding split-brain.
3. **Monotonic Event Buffering & Acknowledged Uploads**:
   - `modules/worker/Supervisor/WorkerEventBuffer.cs`: Thread-safe bounded buffer maintaining monotonic sequence numbering.
   - Batch upload to `POST /api/v1/worker/events` with acknowledgment pruning and fencing conflict (HTTP 409) handling.
4. **Task Sandbox & Platform Isolation**:
   - `modules/worker/Sandbox/TaskSandboxManager.cs`: Creates isolated `/tmp/municlaw/tasks/{taskId}/worktree`, `home`, and `tmp` directories.
   - `modules/worker/Sandbox/SandboxPolicyEnforcer.cs`:
     - Denies access to host Docker sockets (`/var/run/docker.sock`, `/run/docker.sock`).
     - Denies access to cloud metadata services (`169.254.169.254`, `fd00:ec2::254`, `169.254.0.0/16`).
     - Strictly denies directory traversal outside task sandbox boundary.
     - Sanitizes environment: sets isolated `HOME`/`TMPDIR`, strips cloud provider keys and supervisor passwords.
5. **Sandbox Retention & Disk-Pressure Admission**:
   - 7-day retention cleanup from latest terminal run (`CleanupExpiredSandboxesAsync`), while active tasks are protected from cleanup ("cleanup never silently erases active work").
   - Disk-pressure admission rejection: checks free disk space against configured threshold (`MinFreeDiskSpaceBytes`), rejecting admission when host disk is pressured.
6. **OpenCode Supervisor & HTTP/SSE Adapter**:
   - `modules/worker/Harness/OpenCodeSupervisor.cs`: Manages pinned OpenCode `v1.18.32` headless server process on loopback (`127.0.0.1:{port}`) with `OPENCODE_SERVER_PASSWORD` Basic Auth. Strictly rejects non-loopback bindings.
   - `modules/worker/Harness/OpenCodeHarnessAdapter.cs`: Implements `IHarnessAdapter` for session creation, prompt dispatch, diff retrieval, SSE event streaming, and sub-100ms measured abort SLA.
7. **Automated Verification**:
   - Executable test suite in `modules/tests/MuniClaw.Worker.Tests/Program.cs` with 12/12 automated unit and integration tests passing.
   - Full solution build in `MuniClaw.slnx` succeeds with 0 errors and 0 warnings.
