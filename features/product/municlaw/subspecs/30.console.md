# T30: Separate responsive console

Status: Planned.
Depends on: T10, T20.
Can run in parallel with: None.

## Work

- Create the independent frontend/deployment for proposed `ai.muni.dev`, reusing repository-supported React/shadcn and identity conventions.
- Implement Tasks, Projects, Connections, Workspace, and Settings with private onboarding and organization selection.
- Support repository/base-branch/model selection, key entry, queued/running tasks, reconnectable activity, approvals, cancellation, and follow-up turns.
- Show changed files, actual check commands/exit results, estimated usage with unknown states, retention expiry, and reviewed-commit draft PR/MR publication.
- Provide responsive mobile task creation, approvals, result review, and cancellation; keyboard and screen-reader access must work.
- Keep provider keys write-only; no direct browser connection to worker/OpenCode endpoints.

## Acceptance

- Console has separate origin, app shell, and deployment from `cloud.muni.dev`; shared sign-in does not bypass MuniClaw allowlisting.
- Closing/reopening the browser restores task state/history; replay does not duplicate events.
- A stale approval or edited-after-review publication is rejected and requires review of current state.
- Desktop and narrow mobile rendered checks cover onboarding, running/offline/failed tasks, approvals, diffs, and draft delivery.
- Native mobile, messaging, and preview UI are not presented as available features.
