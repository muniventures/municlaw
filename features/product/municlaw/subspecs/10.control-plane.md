# T10: Control plane and integrations

Status: Complete.
Depends on: T00.
Can run in parallel with: T20.

## Work

- Implement private allowlisting, authentication-subject mapping, MuniClaw-owned organizations/memberships, organization authorization, and MuniClaw-owned persistence/migrations. Enforce the one-active-member MVP limit as policy over a multi-user schema.
- Add workspace, project, task/run, event replay, approval, delivery, provider-key metadata, and usage APIs using T00 contracts.
- Implement idempotent task admission, one active run per organization, fenced leases, deadlines, cancellation, and restart reconciliation.
- Connect GitHub.com through installation access and GitLab.com through OAuth; verify current official scopes and token lifecycle before implementation.
- Store tokens/keys in scoped OpenBao paths; add trusted model/Git credential boundaries and revoke/rotate flows. Provider credentials are personal-only in the MVP while metadata and contracts reserve organization scope.
- Implement publication bound to the reviewed repository, base, target branch and commit. Create or update a draft PR/MR using provider-supported attribution. Stop for reconciliation when the remote task branch moved.
- Integrate explicit asynchronous onboarding provisioning through an authorized Minicloud service identity/linkage; ownership checks apply to creation, reuse, and deletion.
- Add retention cleanup and bounded, redacted events; report usage estimates separately from authoritative provider bills.

## Acceptance

- Cross-organization object access, streams, worker identities, credential references, and publication attempts are rejected.
- Concurrent enqueue/claim and duplicate requests do not execute overlapping organization runs or create duplicate PRs/MRs.
- Both Git hosts support repository selection, private checkout, reviewed branch publication, and updating the same draft review request.
- Key/token values never appear in stored events or client responses; revocation blocks new calls and invalidates pending approvals as applicable.
- Offline/unknown execution is reconciled before rescheduling. Approval and publication checks use current authorization and reviewed content versions.

## Implementation & Test Evidence (2026-09-28)

1. **Domain Models & Multi-User Ready Schema with MVP Single-Member Policy**:
   - Implemented in `modules/core/Models/DomainModels.cs` and `ExecutionModels.cs`: `User`, `Organization`, `OrganizationMembership`, `CodingWorkspace`, `RepositoryConnection`, `Project`, `ProviderCredentialReference`, `TaskEntity`, `TaskRun`, `TaskEventRecord`, `ApprovalRequestRecord`, `DeliveryRecord`, and `UsageRecordEntity`.
   - `OrganizationAuthorizationService` enforces that while the relational model is multi-user ready, the MVP policy admits at most one active membership per organization (verified by test).
2. **Task Lifecycle & One-Active-Task Rule**:
   - `TaskLifecycleService`: Enforces idempotent task admission via duplicate request detection, binds tasks to dedicated task branches (`municlaw/task-{id:N}`), manages immutable follow-up runs, and enforces that only one task may be actively executing per organization at a time (other tasks wait in `Queued`).
3. **Worker Dispatch, Fenced Ownership & Lease Expiry**:
   - `WorkerDispatchService`: Handles HTTP long-polling claims, assigns lease tokens with monotonic `FencingToken`, renews leases via heartbeats, queues and delivers commands past cursor, and reconciles expired worker leases to `Failed`.
4. **Approvals & Platform Denial**:
   - `ApprovalService`: Validates content version hash to reject stale approval replays, evaluates capability categories, and guarantees `PlatformDenied` requests cannot be approved.
5. **BYOK Credentials & Revocation Cascades**:
   - `ProviderCredentialService`: Enforces personal-only credential scope for MVP, stores scoped OpenBao reference paths, returns write-only safe metadata, and terminates active runs upon credential revocation.
6. **Delivery & Git Integration**:
   - `DeliveryService` with `MockGitProviderClient`: Enforces publication bound to reviewed commit SHA and target branch, returning draft PR records.
7. **Workspace Provisioning**:
   - `WorkspaceProvisioningService` with `MockMinicloudInfrastructureClient`: Explicit asynchronous onboarding request generating SHA256-hashed one-time supervisor registration tokens.
8. **API Host & SSE**:
   - `modules/api/MuniClaw.Api.csproj` implementing `TasksController`, `ApprovalsController`, `DeliveriesController`, `CredentialsController`, `WorkspacesController`, and `WorkerController` with SSE event replay via cursor headers.
9. **Automated Verification**:
   - 12/12 automated unit and integration tests passing in `modules/tests/MuniClaw.Tests/Program.cs`.
