# T90: End-to-end qualification and operations

Status: Planned.
Depends on: T10, T20, T30.
Can run in parallel with: None.

## Work

- Run connected scenarios on disposable organization VPSes, GitHub/GitLab test repositories, and actual API keys for the three initial providers.
- Cover task creation, setup, edit/test evidence, disconnect/reconnect, approval, draft PR/MR delivery, follow-up, cancel, and explicit resume.
- Exercise worker/OpenCode crashes, API interruption, lease loss, duplicate requests/events, uncertain Git publication, provider rate limits, revoked credentials, and disk/resource exhaustion.
- Verify tenant separation, secret redaction, network/filesystem boundaries, malicious repository configuration, and stale-approval rejection.
- Record build/test evidence and rendered desktop/mobile checks. Document bootstrap, upgrade/rollback, revocation, orphan reconciliation, retention, workspace deletion, and VPS-loss recovery limitations.

## Acceptance

- All functional and failure-path scenarios have reproducible evidence, including both Git hosts and every initial provider.
- No duplicate remote delivery, concurrent stale worker, cross-organization access, raw key leakage, or unauthorized host access.
- Operator can identify failed stages and recover without silently rerunning completed side effects.
- Private release readiness is recorded separately from deployment authorization. No public availability or billing claims.
