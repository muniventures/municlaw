## Qualification Evidence & Operational Verification (2026-09-28)

1. **Connected E2E Lifecycle**:
   - Verified end-to-end flow from user allowlisting $\rightarrow$ dedicated VPS workspace allocation $\rightarrow$ GitHub/GitLab repository connection $\rightarrow$ BYOK personal credentials (OpenAI, Anthropic, DeepSeek) $\rightarrow$ task admission $\rightarrow$ leased worker long-poll claim with monotonic fencing token $\rightarrow$ OpenCode execution $\rightarrow$ monotonic event stream $\rightarrow$ browser SSE cursor replay without duplicate delivery $\rightarrow$ interactive approval $\rightarrow$ reviewed commit draft PR delivery $\rightarrow$ follow-up turns on the same task branch.
2. **Defensive Sandbox Boundaries**:
   - `SandboxPolicyEnforcer` tested against malicious repository configurations:
     - Blocked access to host Docker daemon sockets (`/var/run/docker.sock`, `/run/docker.sock`).
     - Blocked access to cloud link-local metadata services (`169.254.169.254`, `169.254.0.0/16`, `fd00:ec2::254`).
     - Blocked path traversal (`../../../etc/shadow`) escaping task sandbox boundary.
     - Stripped cloud provider credentials and supervisor passwords from child process environment.
3. **Multi-Tenant Isolation**:
   - Verified that users from Organization A cannot access, claim, execute, or publish delivery records for tasks in Organization B (throws 403 Forbidden).
   - Enforced MVP single-member policy: attempting to add a second active user membership to an organization throws `InvalidOperationException`.
4. **Fault Tolerance, Lease Loss & Split-Brain Prevention**:
   - Expired worker lease marks run `Failed` and invalidates lease token.
   - Heartbeat from worker with expired lease receives 410 Gone / `IsLeaseValid == false`, triggering immediate child process termination.
   - Event upload with stale fencing token rejected with 409 Conflict, preventing split-brain writes.
5. **BYOK Security & Revocation Cascades**:
   - Provider credentials stored under scoped OpenBao paths and write-only in API.
   - Revocation cascade immediately terminates all active runs using that credential with `Status: Failed`.
6. **Operations Guide**:
   - Operational guide established at `docs/architecture/operations.md` covering VPS bootstrap, registration tokens, leasing and fencing architecture, sandbox limits, and disaster recovery.
