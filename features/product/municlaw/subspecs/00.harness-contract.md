## Qualification Evidence & Contract Decisions (2026-09-28)

1. **Pinned Release and Licensing**:
   - Release: OpenCode `v1.18.32` (`github.com/anomalyco/opencode`, published 2026-09-21).
   - License: MIT License (`key: "mit"`).
   - Distribution: Standalone binary (`opencode-linux-x64` / `opencode-linux-arm64`) and headless server mode (`opencode serve --port <port> --hostname 127.0.0.1`).
   - Authentication: Server-level HTTP Basic Auth enforced via `OPENCODE_SERVER_PASSWORD` (default user `opencode`).

2. **Harness Endpoints & Event Protocol**:
   - Session Lifecycle: `POST /session`, `GET /session/{sessionID}`, `GET /session/{sessionID}/diff`.
   - Prompt & Abort: `POST /session/{sessionID}/prompt_async` (returns HTTP 204 immediately); `POST /session/{sessionID}/abort` terminates active prompt/tool execution with sub-second latency (measured 2.3ms in prototype).
   - Event Stream: Server-Sent Events (SSE) via `GET /event`.
   - Permissions: `GET /permission`, `POST /permission/{requestID}/reply`.
   - Canonical Event Mapping: Implemented in `MuniClaw.Core.Contracts.Harness.HarnessEventMapper`. Raw events (`EventSessionNextStepStarted`, `EventSessionNextStepEnded`, `EventSessionNextToolCalled`, `EventSessionNextToolSuccess`, `EventPermissionAsked`, `EventSessionDiff`, `EventSessionError`) map to canonical `TaskEventType`. Internal and transient TUI/browser events are filtered out.

3. **Provider Proxy & Credential Boundary**:
   - OpenCode supports custom provider configurations with custom `baseURL` (e.g. `http://127.0.0.1:<proxy_port>/v1`).
   - Trusted supervisor runs a local model proxy outside the sandbox.
   - Long-lived provider keys (OpenAI, Anthropic, DeepSeek) are stored in OpenBao/supervisor memory and injected exclusively by the proxy.
   - Shell commands inside the sandbox cannot inspect or export raw provider API keys.

4. **Task & TaskRun State Machines**:
   - `Task`: `Open` -> `Archived`.
   - `TaskRun`: `Queued` -> `Preparing` -> `Running` -> `AwaitingInput` | `Completed` | `Failed` | `Cancelling`; `Cancelling` -> `Cancelled`.
   - State transition validation enforced in `MuniClaw.Core.Contracts.Tasks.TaskRunStateTransitions`. Terminal states (`Completed`, `Failed`, `Cancelled`) cannot restart.

5. **Approval Capabilities & Inviolable Policy**:
   - Stable categories: `WorktreeReadWrite`, `LocalGit`, `SandboxedCommand`, `PackageNetwork`, `ExternalNetwork`, `DestructiveWorkspace`, `SetupConfig`, `RemoteGitWrite`, `DraftDelivery`, `PlatformDenied`.
   - Policy Engine: `MuniClaw.Core.Contracts.Approvals.CapabilityPolicyEngine`.
   - Inviolability rule: `PlatformDenied` (host files, host Docker sockets, metadata service `169.254.169.254`, private management networks, raw credentials) strictly evaluates to `Deny` regardless of user or repository configuration.

6. **Worker Long-Poll & Leased Fencing Protocol**:
   - Claim contract: `WorkerClaimRequest` / `WorkerClaimResponse` with leases and monotonically increasing `FencingToken`.
   - Heartbeat & Command cursor: `WorkerHeartbeatRequest` / `WorkerHeartbeatResponse` renewing lease and delivering pending `WorkerCommand` items past `LastAcknowledgedCommandCursor`.
   - Event batch upload: `WorkerEventBatchUpload` with monotonic `TaskEventDto.SequenceNumber` and `WorkerEventBatchAck`.

7. **Automated Verification**:
   - Executable contract suite in `modules/tests/MuniClaw.Tests/` passing with 6/6 tests covering state transitions, terminal immutability, capability evaluation, cursor serialization, and event mapping.
