# Subspec: Concurrency and Queue Visualization in Console UI

Task: `T20`
Status: Complete

## Scope

- Concurrency Slot Progress bar: displays active executing runs vs quota (`Active Tasks: X / Y`).
- Task List queue badges: displays `Queued #1`, `Queued #2` for tasks waiting for execution slots.
- Task Detail queue banner: when a task is in `Queued` state, displays informational banner indicating position in queue and reassuring user that execution will begin automatically.
- Settings page concurrency configuration: allows organization administrators to view and configure `MaxConcurrentRuns`.

## Summary of Changes

1. **TypeScript Types (`app/api/types.ts`)**:
   - Added `queuePosition?: number` to `TaskRun`, `TaskEntity`, and `TaskItem`.
   - Added `TaskQueueStatus` interface (`queuePosition?: number | null`, `activeRuns: number`, `maxConcurrentRuns: number`).
   - Added `maxConcurrentRuns?: number` to `Organization`.

2. **API Client (`app/api/tasks.ts`)**:
   - Added `getTaskQueueStatus(taskId: string): Promise<TaskQueueStatus>` calling `/api/v1/tasks/{taskId}/queue`.

3. **Task List Queue Badges (`app/modules/Tasks/components/TaskList.tsx`)**:
   - Updated `getStatusBadge` to render a styled amber badge with clock icon showing `Queued` and position if present (e.g. `Queued #1`, `Queued #2`).
   - Enhanced task status filtering to correctly match queued runs and items.

4. **Resource Usage & Concurrency Slot Progress (`app/modules/Tasks/components/UsageCard.tsx`)**:
   - Added active concurrency slot display (`Active Concurrency: X / Y slots in use`) with visual capacity progress bar and percentage indicator.

5. **Tasks Module Overview (`app/modules/Tasks/TasksModule.tsx`)**:
   - Added organization concurrency slot progress visualizer (`Active Tasks: X / Y slots in use`) with capacity bar, active count, queued count, and total quota chips.

6. **Task Detail Queued Banner (`app/modules/Tasks/TaskDetailModule.tsx`)**:
   - Added prominent informational banner for runs in `queued` status: `Waiting in Queue — Position #X. Execution will automatically start when an active task slot becomes available.`
   - Connected `getTaskQueueStatus` to query active runs, max concurrent runs, and real-time queue position.
   - Forwarded `activeRuns` and `maxConcurrentRuns` to `UsageCard`.

7. **General Settings Concurrency Quota Editor (`app/modules/Settings/SettingsModule.tsx`)**:
   - Added Concurrency Quota card under General settings with select dropdown and number input (1 to 10 slots).
   - Allows organization administrators to view and adjust `MaxConcurrentRuns` with validation and persistent saving.
