# Subspec: Concurrency Scheduler and Task Queue

Task: `T10`
Status: Complete

## Scope

- Concurrency Quotas: `Organization.MaxConcurrentRuns` (default 2, configurable).
- `TaskQueueService`:
  - `GetActiveRunsCountAsync(Guid orgId)`
  - `GetQueuePositionAsync(Guid orgId, Guid runId)`
  - `PromoteNextQueuedTaskAsync(Guid orgId)`: promotes oldest `Queued` task to `Preparing` if slots are available.
  - `GetQueuedRunsAsync(Guid orgId)`: retrieves all queued runs in FIFO order with updated 1-based queue positions.
- `TaskLifecycleService`:
  - Modifies `CreateTaskAsync` to admit tasks directly to `Preparing` if active runs < quota; otherwise places run in `Queued` and assigns `QueuePosition`.
  - Enforces strict concurrency limits when `MaxConcurrentRuns == 1` and `StrictConcurrencyLimit` is requested.
  - On run reaching `Completed`, `Failed`, or `Cancelled`, automatically calls `PromoteNextQueuedTaskAsync`.
  - Exposes `CancelTaskAsync`, `ReconcileTerminalRunAsync`, and `ReconcileTerminatedRunsAsync` for triggering promotion on terminal state transitions.
- API endpoints:
  - `GET /api/v1/tasks/{taskId}/queue` (and `GET /api/v1/organizations/{organizationId}/tasks/{taskId}/queue`) returning `{ queuePosition, activeRuns, maxConcurrentRuns }`.

## Implementation Details

1. **Domain Models (`DomainModels.cs` / `ExecutionModels.cs`)**:
   - Added `public int MaxConcurrentRuns { get; set; } = 2;` to `Organization`.
   - Added `public int? QueuePosition { get; set; }` to `TaskRun` (partial class definition).

2. **Task Queue Service (`TaskQueueService.cs`)**:
   - Interface `ITaskQueueService` and implementation `TaskQueueService` providing:
     - `GetActiveRunsCountAsync(Guid organizationId)`: Counts active runs (`Preparing`, `Running`, `AwaitingInput`, `Cancelling`).
     - `GetQueuePositionAsync(Guid organizationId, Guid runId)`: Resolves 1-based FIFO queue position for queued runs.
     - `GetQueuedRunsAsync(Guid organizationId)`: Returns all queued runs in strict `CreatedAt` FIFO order and syncs `QueuePosition`.
     - `PromoteNextQueuedTaskAsync(Guid organizationId)`: Atomically checks available quota (`active < maxConcurrent`), transitions the oldest queued run to `Preparing`, sets `StartedAt`, appends a `StepStarted` event, and updates positions of remaining queued runs.

3. **Task Lifecycle Service (`TaskLifecycleService.cs`)**:
   - Injected `ITaskQueueService` (defaulting to `new TaskQueueService(_store)`).
   - In `CreateTaskAsync`: Checks active running tasks against `org.MaxConcurrentRuns`. If active < quota, directly starts run in `Preparing` with `StartedAt` timestamp and `StepStarted` event; otherwise keeps in `Queued` with computed `QueuePosition`. Preserves single-task rejection when `org.MaxConcurrentRuns == 1` and `StrictConcurrencyLimit == true`.
   - Automatically promotes the next queued task in `CancelRunAsync`, `CancelTaskAsync`, and `ReconcileTerminalRunAsync`.

4. **Tasks Controller (`TasksController.cs`)**:
   - Injected `ITaskQueueService` and `IMuniClawStore`.
   - Added `GET /api/v1/tasks/{taskId}/queue` and `GET /api/v1/organizations/{organizationId}/tasks/{taskId}/queue` returning `{ queuePosition, activeRuns, maxConcurrentRuns }`.
