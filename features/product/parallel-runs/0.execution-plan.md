## Phase plan

1. **T10 (Core/API)**:
   - Add `MaxConcurrentRuns` property to `Organization`.
   - Implement `TaskQueueService` managing FIFO queueing, calculating queue positions, and promoting tasks on terminal transitions.
   - Update `TaskLifecycleService`: allow concurrent task runs up to `Organization.MaxConcurrentRuns`; transition overflow tasks to `Queued` instead of rejecting; trigger queue promotion on run completion/failure/cancellation.
   - Expose queue status and organization concurrency settings endpoints in `TasksController` and `OrganizationsController`.
2. **T20 (Console UI)**:
   - Add TypeScript types for queue metadata and concurrency quota.
   - Update `TaskList.tsx` and `UsageCard.tsx` with active slot progress and queue position tags.
   - Add queue waiting banner in `TaskDetailModule.tsx` when a task is in `Queued` state.
   - Add concurrency limit editor in `SettingsModule.tsx`.
3. **T90 (Qualification)**:
   - Automated tests in `modules/tests/MuniClaw.Tests/Program.cs` verifying parallel task creation, FIFO queue ordering, quota enforcement, and automatic promotion upon run completion and cancellation.
